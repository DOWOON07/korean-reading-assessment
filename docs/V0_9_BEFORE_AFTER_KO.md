# v0.9 전후 비교: 핵심 후보와 연구 확장 분리

기준: v0.8.0 로컬 상태 → v0.9.0 로컬 상태  
목적: 교수님 피드백 이후 검사 구성개념의 역할이 어떻게 달라졌는지 한눈에 설명한다.

## 요약

| 항목 | 이전 | v0.9 이후 |
|---|---|---|
| 버전 | v0.8.0 | v0.9.0 |
| A 해독 | 2×2 문항 구조만 존재 | 2×2 청사진 버전·셀 감사·표준화 전 검증 게이트를 세션에 기록 |
| B 기본 | 연결글 낭독과 ROAR/TOSREC 계열을 모두 핵심처럼 실시 | 연결글 낭독만 기본; ROAR/TOSREC는 기본 OFF 연구 확장 |
| C 형태소 | 어휘·문장·듣기와 한 총점에 포함 가능 | 기본 OFF 심화 연구 확장; 핵심 점수·권고와 분리 |
| D 고차 문해 | 사실·추론·평가·복수 글을 모두 기본 실시 | 사실·추론 기본; 평가·복수 글은 기본 OFF 연구 확장 |
| 참여자 결과 | 선택형 모듈 전체를 묶어 표시 | 핵심 후보만 표시; 연구 확장 결과는 연구자용에서만 별도 표시 |
| 다음 단계 권고 | 확장 과제의 낮은 점수도 권고에 섞일 수 있음 | 핵심 후보만 임시 권고 규칙에 사용 |
| 용어 | `실시·채점`이 표준화 완료처럼 보일 수 있음 | `핵심 후보`, `연구 확장·별도 채점`, `표준화 전`을 명시 |

## 화면에서 바뀐 것

1. 첫 화면의 B 카드에는 `핵심: 연결글 낭독 · 선택: 디지털 연구 과제`가 보인다.
2. C 카드에는 형태소, D 카드에는 평가·두 글 비교가 선택 과제임이 보인다.
3. 새 검사 → 연구자 설정에 다음 스위치가 생겼다.
   - B 디지털 읽기 연구 확장
   - C 형태소 인식 심화 과제
   - D 고차 문해 연구 확장
4. 세 스위치는 기본값이 꺼져 있다.
5. 경로 확인 화면은 각 하위검사를 `핵심 후보 · 실시`, `연구 확장 · 선택 안 함`, `연구 확장 · 별도 채점`으로 구분한다.
6. 선택한 확장은 연구자용 결과에서만 별도 요약되며 핵심 점수에 합쳐지지 않는다.

## 왜 이렇게 바꿨는가

- ROAR/TOSREC 형식에는 연구 근거가 있지만 현재 한국어 문항의 국내 규준이 없다.
- 한국어 유창성의 더 직접적인 기본 지표는 연결글을 소리 내어 읽을 때의 정확도와 속도다.
- 형태소 인식은 한국어 읽기를 설명할 수 있지만 효과가 연령·어휘·과제에 따라 달라 전 연령 핵심 총점으로 쓰기에는 추가 검증이 필요하다.
- 고차 문해는 중요하지만 초기 해독이 어려운 아동부터 성인까지 같은 필수 문항으로 제시하면 검사 목적과 난이도가 섞인다.

## 의도적으로 하지 않은 것

- KOLRA, CLT-R, NISE-B·ACT의 저작권 있는 실제 문항을 복제하지 않았다.
- 기존 후보를 국내 공인검사의 규준으로 환산하지 않았다.
- 형태소 과제를 삭제하지 않았다. 연구 질문과 대상 연령에 따라 켤 수 있게 보존했다.
- ROAR/TOSREC 결과를 진단 또는 핵심 읽기 수준으로 표시하지 않았다.

## 남은 개발

다음 문항 개발은 40–45초 시간제한 한국어 단어 낭독 후보군을 만들고, 빈도·친숙도·음절 수·음운배열확률을 맞춘 뒤 전문가 CVI와 파일럿 문항분석을 거치는 순서다. 형태소는 합성어·접사·형태소 관계 과제로 분리해 연령별 증분타당도를 확인한다. 이 측정 결과가 나온 뒤에만 핵심 편입 여부를 다시 결정한다.
