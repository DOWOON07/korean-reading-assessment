# 실제 음성 ASR 검증 절차

## 목적

자동 음성인식이 참여자의 읽기 오류를 얼마나 정확히 보존하고, 자동채점이 사람 판정과 얼마나 일치하는지 분리해 검증한다. CER/WER가 낮아도 읽기 오류를 정상 발음으로 고쳐 적으면 자동채점에는 부적합할 수 있으므로 전사 정확도와 채점 정확도를 함께 보고한다.

## 현재 상태

- 계산 코드: `scoring.js`의 `transcriptionError`, `asrBenchmarkSummary`
- 실행 도구: `node tools/asr_benchmark.mjs <benchmark.json>`
- 실제 한국어 녹음 기준 자료: 아직 없음
- 따라서 현재 결과지에는 검증 성능을 확정 수치로 표시하지 않는다.

## 개발용 녹음 구성

연구 참여자 모집과 무관한 팀 내부 비식별 개발 녹음으로 먼저 흐름을 점검한다.

1. 실제단어·비단어의 표준 읽기
2. 의도적 대치·생략·삽입
3. 반복·분절·자기수정
4. 느린 낭독·빠른 낭독
5. 낮은 음량·배경 소음·마이크 거리 변화

각 녹음에는 사람이 들은 그대로 작성한 축어 전사, 사람 정오 판정, 음질 조건, 장치 정보를 붙인다. 연구 참여자 자료를 사용할 때는 별도의 연구윤리·동의·보관 절차를 따른다.

## 필수 지표

| 지표 | 의미 |
|---|---|
| CER | 사람 축어 전사 대비 글자 편집 오류율 |
| WER | 사람 축어 전사 대비 어절 편집 오류율 |
| 문항 일치율·Cohen's κ | 사람 정오 판정과 자동 정오 판정의 일치 |
| 오류 유형별 precision/recall | 대치·생략·삽입·반복 등을 얼마나 정확히 찾는지 |
| real-time factor | 분석시간 ÷ 음성길이. 1 이하면 음성길이보다 빠름 |
| 실패율 | 모델 로드, 전사, 타임스탬프 생성이 끝나지 않은 비율 |

## 입력 예시

```json
{
  "rows": [
    {
      "id": "RW-I-01",
      "referenceTranscript": "국물",
      "asrTranscript": "궁물",
      "humanScore": "INCORRECT",
      "autoScore": "CORRECT",
      "audioSeconds": 1.8,
      "elapsedMs": 950
    }
  ]
}
```

## 해석 원칙

- 전체 평균만 제시하지 않고 실제단어/비단어, 성인/아동 후보, 음질 조건별로 나눈다.
- 비단어와 음운변동 문항은 따로 본다.
- 모델·양자화·브라우저·장치가 바뀌면 새 조건으로 다시 측정한다.
- 합격 기준은 실제 자료 분포와 연구 목적을 보고 사전에 정하며, 현재 임의 기준을 만들지 않는다.
