## 이번 변경으로 해결된 것

- 연구자가 같은 공식자료와 규칙으로 B 낱말 목록을 다시 만들 수 있다.
- 낱말 읽기 효율과 연결글 유창성을 한 통계로 섞지 않는다.
- 형태소 과제가 측정하려는 `낱말 구조 조작`에 더 직접 가까워졌다.
- 실제 고정 음원이 없는데도 TTS 교체가 완료된 것처럼 보이는 위험을 막았다.

## 코드만으로 해결했다고 표시하지 않은 것

- 60개 낱말의 연령별 난이도·변별도·절단점
- A 비단어의 말뭉치 음소배열 확률 매칭
- C 형태소 문항의 선택지 기능과 증분타당도
- 실제 고정 한국어 음원의 발음·식별률·사용권 확인
- 연령 규준, 신뢰도, DIF, 진단 정확도

이 항목은 실패나 누락이 아니라 다음 파일럿의 측정 대상이다.
