# v0.10 로컬 확인 매뉴얼

## 1. 최신 화면 열기

프로젝트 폴더의 터미널에서 다음을 실행한다.

```powershell
npm start
```

브라우저에서 <http://localhost:8080>을 열고 `Ctrl+Shift+R`로 강력 새로고침한다. 화면 위 배지가 `연구용 프로토타입 v0.10.0`인지 먼저 확인한다.

## 2. B 45초 낱말 읽기 확인

1. 첫 화면에서 `검사자 도구`를 펼친다.
2. `B 읽기 유창성` 모듈만 시작한다.
3. 정보 입력에서 `데모`를 선택하고 마이크 점검을 마친다.
4. 연습 지문 뒤 본검사 시작을 누른다.
5. `가게 겨울 구름 …`으로 시작하는 60개 낱말 목록이 보이는지 확인한다.
6. 화면 크기를 바꿔도 5열 × 12행과 낱말 순서는 유지되고, 글자 크기만 제한 범위 안에서 조절되며 가로 스크롤이 생기지 않는지 확인한다.
7. 녹음 버튼을 누른 뒤 45초가 되면 버튼을 다시 누르지 않아도 녹음이 끝나는지 확인한다.
8. 안내가 `끝까지 못 읽어도 괜찮습니다`라고 말하는지 확인한다.
9. 이어지는 연결글은 기존처럼 끝까지 읽고 수동 종료되는지 확인한다.

합격 기준: 낱말 목록만 45초 자동 종료되고 연결글은 자동 종료되지 않는다.

## 3. C 형태소 과제 확인

1. 새 검사에서 C를 선택한다.
2. 정보 입력의 연구자 설정에서 `형태소 인식 연구 확장`을 켠다.
3. C 기본 어휘·문장·듣기 뒤 `낱말 구조 알기` 화면으로 이동한다.
4. 연습에서 `돌로 만든 다리 → 돌다리`가 보이는지 확인한다.
5. 본문에 합성어 결합, 합성어 분해, 파생어 결합, 파생어 분해 문제가 나오는지 확인한다.
6. 본검사에서 맞고 틀림을 알려 주지 않는지 확인한다.

합격 기준: 예전의 `밤송이/밤하늘`, `소방관/도서관`, `풋볼` 같은 동형 글자 찾기 문제가 나오지 않는다.

## 4. 결과 분리 확인

1. B 검사를 끝낸 뒤 연구자용 상세 결과를 연다.
2. 자동 분석을 실행한다. 처음 실행은 Whisper small 다운로드 때문에 시간이 걸릴 수 있다.
3. `시간제한 낱말 읽기 후보` 표에서 `45초 정확 낱말`과 `시도 낱말`을 확인한다.
4. 바로 아래 `연결글 읽기 정확도와 속도` 표가 별도로 있는지 확인한다.
5. 하위검사 표에서 45초 값 옆에 `규준 없음`이 표시되는지 확인한다.

합격 기준: 45초 낱말 값이 연결글 분당 정확 어절·음절 계산에 섞이지 않는다.

## 5. 문항 근거 자동검사

터미널에서 실행한다.

```powershell
npm run check
```

다음을 확인한다.

- B 낱말 60개, 등급별 20개, 중복 없음, 모두 2음절 명사
- v0.10 버전 일치
- 45초 자동 종료와 결과 분리 코드 존재
- C 네 형태소 유형과 옛 동형 글자 문항 제거
- 고정 음원 manifest가 비어 있으면 `통과(대기)`로 표시하고 READY로 오인하지 않음

## 6. TTS 상태 확인

현재 고정 음원은 아직 등록되지 않았다. 따라서 듣기 문항을 실행하면 기기별 한국어 음성이 잠정 사용되고, 연구자용 기술 기록에 음성명과 재생시간이 남아야 한다. 이는 v0.10의 의도된 상태다.

TTS가 실제로 교체되었다고 판단할 기준은 다음 네 가지가 모두 충족될 때다.

1. 같은 문항에서 모든 기기에 같은 로컬 고정 파일이 재생된다.
2. 파일별 사용권·출처·문장 버전·해시가 manifest에 있다.
3. 발음 정확성·목표 낱말 식별·속도·왜곡 청취평가를 통과했다.
4. `npm run check`가 고정 음원 파일과 해시를 통과시킨다.
