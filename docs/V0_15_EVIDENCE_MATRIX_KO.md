## 3. 글꼴·크기·행간·배치

한국어 읽기능력평가에 대해 모든 연령·난독증·지적장애 대상에게 동일하게 최적인 단일 웹 글꼴/크기 표준은 확인되지 않았다. 따라서 특정 숫자를 “검증 완료 최적값”이라고 부르지 않고, 접근성 표준과 읽기 화면 원칙을 만족하는 **통제된 후보 사양**으로 둔다.

| 항목 | 현재 사양 | 이유 | 수준 |
|---|---|---|---|
| 자극 글꼴 | `Noto Sans KR → Malgun Gothic → sans-serif` | 화면용 고딕 계열, 장식이 적고 다양한 기기에서 한국어 대체 가능. 실제 사용 글꼴도 저장 | B+P |
| 낱말 자극 | `clamp(4rem, 10vw, 8rem)`, 굵기 800, 행간 1.2 | 한 문항에 시선을 집중시키고 화면 폭에 반응. 보정 시 목표 약 18mm | B+P |
| 지문 | `1.3~1.75rem`, 행간 1.7, 폭 34ch, 왼쪽 정렬 | 긴 줄·좁은 행간·양쪽 정렬에서 생기는 추적 부담을 줄임 | B+P |
| 선택지 | `1.05~1.25rem`, 행간 1.65, 폭 42ch | 지시와 보기를 읽을 수 있게 하되 낱말 자극과 시각적 역할을 구분 | B+P |
| 대비 | 전경 `#172133`, 배경 `#f7f9fc`, AA 4.5:1 이상 | WCAG 2.2의 일반 텍스트 최소 대비 기준보다 여유 있게 설정 | A+C |
| 조작 영역 | 최소 44 CSS px | 작은 표적에 의한 운동 오류를 줄이고 WCAG 목표 크기 취지를 충족 | A+C |
| 물리 크기 보정 | ID-1 카드 85.6mm, 100mm 자, 보정 안 함 | CSS px는 물리 크기를 보장하지 않으므로 장치 간 근사 보정. 특정 소지품을 강제하지 않음 | C+P |

`clamp()`는 작은 화면에서 계속 작아지는 것이 아니라 최소값과 최대값 사이에서만 반응한다. 카드/자 보정값이 있으면 mm 목표를 CSS px로 다시 계산한다. 이는 화면 크기 차이를 줄이지만 시거리·시력·운영체제 배율까지 자동으로 같게 만들지는 않는다.

관련 코드: `assessment-spec.js`의 `VISUAL`, `CALIBRATION`, `applyVisualTokens()`.

## 6. C 언어 이해와 형태소

어휘·문장·듣기 이해는 읽기 이해의 언어이해 축을 구성하는 핵심 후보로 둔다. 형태소 인식은 읽기 발달과 관련된 연구 근거가 있으나 현재 국내 핵심 표준검사의 중심 점수로 직접 등치하지 않으므로 연구 확장으로 분리한다.

기존의 “같은 글자 찾기”는 형태소 의미를 충분히 측정하지 못해 합성어/파생어의 결합·분해로 교체했다. 이 변경으로 과제-구인 정렬은 좋아졌지만, 문항의 난이도·변별도·연령 적합성이 검증됐다는 뜻은 아니다.

## 7. C·D 지문과 선택지 감사

한국어 텍스트 난이도는 길이 하나로 결정되지 않는다. v0.15는 어절·음절·문장 길이, 어휘등급 가용률, 연결어·내포·피동/사동·부정 표지를 **기술 프로파일**로 저장한다. 학년을 자동 예측하지 않는다.

선택지는 정답 누락/중복, 중복 보기, 정답 길이 단서, 보기 길이 편차를 검사한다. 의미가 그럴듯한 오답인지, 문화적 편향이 없는지, 실제 추론을 요구하는지는 자동 코드가 판정하지 않는다.

근거: [한국어 읽기 텍스트 난이도 측정 공식 연구 서지](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002560113). 현재 구현은 해당 연구 공식을 임의 복제한 학년 예측기가 아니라, 공식에 필요한 특징을 단계적으로 수집하는 기술 감사다.

## 9. ASR와 자동채점

Whisper small은 참여자 흐름에서 미리 받지 않고 연구자가 분석 버튼을 누를 때만 준비한다. 목적은 검사 중 CPU/GPU·메모리 경쟁과 초기 다운로드 지연을 제거하는 것이다. large-v3-turbo는 비교 후보이지 기본 실시 조건이 아니다.

공개자료 1단계는 다음과 같다.

- [KsponSpeech](https://doi.org/10.3390/APP10196936): 한국어 자발화 ASR 기준
- [Mozilla Common Voice datasets](https://commonvoice.mozilla.org/en/datasets): 한국어 낭독음성 공개자료

두 자료에서 CER/WER/RTF가 좋아도 목표 집단의 읽기 오류를 정확히 구분한다는 뜻은 아니다. 최종 단계는 실제 대상 집단 원음성에 사람 축어 전사와 사람 정오판정을 붙여 CER/WER·문항 일치율·Cohen's κ를 계산하는 것이다.

## 10. 파일럿 문항통계

| 지표 | 코드에서 계산 | 해석 | 주의 |
|---|---|---|---|
| 난이도 p | 정답자 비율 | 너무 쉽거나 어려운 후보 찾기 | 표본 특성에 따라 달라짐 |
| 수정 문항-총점 상관 | 해당 문항을 뺀 총점과 상관 | 같은 구인을 구분하는지 점검 | n이 작으면 불안정 |
| Cronbach α | 모든 참가자가 같은 문항을 푼 완전자료에서 계산 | 내적 일관성 기술 | 단일차원성·타당도를 보장하지 않음 |
| 집단별 원시 p 차이 | 연령구간별 정답률 최대 차이 | 집단 차이 후보 우선 검토 | 정식 DIF가 아님 |

병렬형 동등성과 DIF를 말하려면 충분한 표본, 공통문항/동등화 설계, IRT 또는 적절한 회귀·Mantel-Haenszel 분석이 추가로 필요하다.

## 12. 출처 사용 원칙

문헌은 세 가지 역할로만 사용한다.

1. 구인과 과제 형식을 정한다.
2. 후보 문항과 시스템 품질 규칙을 만든다.
3. 실제 데이터로 무엇을 검증해야 하는지 정한다.

문헌을 사용했다는 사실만으로 현재 문항의 규준·타당도·진단 정확도가 생기지는 않는다. v0.15의 핵심 개선은 이 경계를 코드와 결과지에서 지우지 않은 것이다.
