# v0.8 로컬 확인 매뉴얼

목표: 교수 피드백이 실제 화면·흐름에 반영됐는지 사용자가 직접 확인한다.  
대상: `연구용 프로토타입 v0.8.0`  
주의: 자동 테스트는 통과했지만, 아래 눈검사는 사용자 확인 항목이다.

## 1. 실행

```powershell
cd C:\LDW\graduate_research\korean-reading-assessment
npm start
```

브라우저에서 `http://localhost:8080`을 연다. 예전 화면이 보이면 `Ctrl+F5`로 새로고침한다. 우측 상단과 첫 화면에 `연구용 프로토타입 v0.8.0`이 보이면 새 코드다.

## 2. 10분 핵심 확인

### A. 첫 화면

경로: `#home`

- [ ] 제목이 `내 읽기 모습을 알아봅니다.`이다.
- [ ] 주 버튼이 `읽기 확인 시작` 하나로 보인다.
- [ ] `표준화 전 연구판`, 진단·등급이 아니라는 문구가 보인다.
- [ ] A–D 시연·ASR·TTS는 `검사자·연구자 도구`를 펼쳐야 보인다.
- [ ] 좁은 창에서도 제목·버튼·3단계 경로가 겹치지 않는다.

설명도: [첫 화면](images/v0.8/01-home-annotated.svg)

### B. 정보 입력

경로: `읽기 확인 시작`

- [ ] 기본 화면에는 참여자 코드, 연령, 분량, 다음 버튼만 먼저 읽힌다.
- [ ] `연구자 설정`을 펼치기 전에는 순서 무작위와 도움조건 설명이 보이지 않는다.
- [ ] 펼치면 체크박스와 두 줄 설명의 세로 위치가 맞는다.
- [ ] `L0/L1/L2` 대신 쉬운 설명이 보인다.
- [ ] D 모듈을 골라도 도움 방식 비교가 기본 체크되어 있지 않다.

### C. 환경 확인

경로: 정보 저장 → 환경 확인

- [ ] `카드로 맞추기`, `자로 맞추기`, `지금 크기 사용`이 있다.
- [ ] 카드에서 자로 바꾸면 막대 문구가 `0–10 cm`로 바뀐다.
- [ ] `지금 크기 사용`을 고르면 막대와 슬라이더가 숨고 진행할 수 있다.
- [ ] 카드 번호·개인정보를 쓰지 않는다는 문구가 있다.
- [ ] 화면/글꼴/대비/조작/음원은 접힌 `연구자용 환경 기록` 안에만 있다.
- [ ] 어떤 보정 방법에서도 거리·배율 두 체크 뒤 `환경 확인 완료`가 열린다.
- [ ] `음성인식 모델 준비 중` 때문에 버튼이 막히지 않는다.

설명도: [환경 확인](images/v0.8/02-preflight-annotated.svg)

### D. 마이크

- [ ] 마이크 확인 전/중 스크롤이 부드럽다.
- [ ] 4초 확인 뒤 ASR 모델 다운로드 문구가 생기지 않는다.
- [ ] `음성 자동 분석은 검사 중에 실행하지 않습니다`가 보인다.
- [ ] 입력이 정상일 때 다음 단계 버튼이 나타난다.

### E. A 모듈

경로: 처음 화면 → 검사자·연구자 도구 → `A 글자·소리/해독`

- [ ] 낱말 읽기 화면에 문항 ID, `실제단어`, `비단어`, `비음화` 태그가 보이지 않는다.
- [ ] 녹음 완료 뒤 `녹음 소리를 조금 크게 듣기`가 나타난다.
- [ ] 녹음 직후에는 저장·재생 안내만 보이고 발화 시작 시각, 발화 길이, 긴 멈춤 횟수 같은 연구자용 수치는 보이지 않는다.
- [ ] 켠 상태와 끈 상태의 재생 크기가 다르고 저장 원음은 다시 녹음하지 않는 한 그대로다.
- [ ] 녹음 연습 뒤 `연습 끝 / 본검사 시작` 화면이 나온다.
- [ ] 글자·소리 처리 연습에서는 매 연습문항에만 정오 피드백이 나온다.
- [ ] 본검사 시작 뒤에는 `맞았어요!`나 정답이 나오지 않는다.
- [ ] 검사 중 Whisper 다운로드·분석 문구가 없고 스크롤/버튼이 멈추지 않는다.

### F. B 모듈

경로: 처음 화면 → 검사자·연구자 도구 → `B 읽기 유창성`

- [ ] 녹음 화면의 지문 폭·행간이 일정하고 왼쪽 정렬이다.
- [ ] 단어 재인 연습 뒤 본검사 준비 화면이 나온다.
- [ ] `본검사 시작`을 누르기 전 첫 시간제한 낱말이 보이지 않는다.
- [ ] F/J를 눌러 답해도 페이지가 위로 튀지 않는다.
- [ ] 첫 자극부터 응답 가능하다.
- [ ] 연습만 피드백, 본검사 무피드백이다.

설명도: [검사 화면](images/v0.8/03-assessment-annotated.svg)

### G. C/D 모듈

- [ ] 지문은 왼쪽 정렬, 최대 폭 안에서 줄바꿈되고 줄이 지나치게 길지 않다.
- [ ] 질문과 보기는 같은 크기·간격·버튼 형식을 쓴다.
- [ ] 연구자용 문항 유형은 참여자에게 별도 태그로 나오지 않는다.
- [ ] D 기본 검사 지문에 형광펜 표시가 없다.
- [ ] 연구자 설정에서 도움 방식 비교를 켠 경우에만 검사 끝에 핵심 문장 표시 조건이 나온다.

### H. 완료와 결과

- [ ] 마지막 응답 뒤 `응답을 안전하게 저장했습니다`가 즉시 나온다.
- [ ] 수분간 자동채점을 기다리지 않고 `참여자용 결과 보기`를 누를 수 있다.
- [ ] 참여자용 요약이 기본으로 열린다.
- [ ] 활동명, 정답 수, `분석 전` 상태가 쉬운 말로 보인다.
- [ ] 또래 비교·백분위·진단을 제공하지 않는 이유가 보인다.
- [ ] `연구자용 상세`을 눌러야 오류 유형·근거·자동분석 버튼이 보인다.
- [ ] 기술 사양표가 참여자용 결과에 나오지 않는다.

설명도: [결과 화면](images/v0.8/04-results-annotated.svg)

## 3. TTS 확인

경로: 처음 화면 → 검사자·연구자 도구 → `TTS 후보 검증`

- [ ] 기기에 SunHi Natural이 있으면 목록 맨 위에 온다. 없으면 사용 가능한 한국어 자연음 후보가 온다.
- [ ] 0.90×가 `시작값`으로 표시된다.
- [ ] 재생 뒤 WPM, SPM, 후보 범위 안/밖이 보인다.
- [ ] 재생하지 않고 저장하려 하면 먼저 재생하라는 안내가 나온다.
- [ ] 평가 3개를 모두 고르지 않으면 저장이 막힌다.
- [ ] 220–280 SPM이고 세 평가가 모두 4점 이상이면 `파일럿 후보`로 저장된다.
- [ ] `물`, `뿔`, `풀`, `불`, 받침·경음 낱말을 직접 듣고 부자연스러우면 고정하지 않는다.

중요: 이 확인은 후보 선정이다. 점수용 고정 음원은 별도의 전문가 검수와 대상자 식별률을 통과해야 한다.

## 4. 연구자 ASR 확인

경로: 검사 완료 → `연구자 자동 분석` 또는 처음 화면 → `자동 채점 검증`

- [ ] 이 버튼을 누르기 전 네트워크에서 Whisper 모델을 받지 않는다.
- [ ] 누른 뒤에만 small 모델 진행률이 나타난다.
- [ ] 분석 중에도 이미 저장된 참여자 검사는 종료 상태로 유지된다.
- [ ] 완료 뒤 자동 후보 점수가 생긴다.
- [ ] 사람 전사/판정과 CER, WER, RTF, 일치율, κ를 비교할 수 있다.

## 5. 화면 크기별 확인

브라우저 개발자 도구 또는 창 크기로 각각 확인한다.

| 조건 | 합격 기준 |
|---|---|
| 1280×720 | 주 행동과 자극이 첫 화면에서 보이고 겹치지 않음 |
| 1920×1080 | 글줄이 화면 전체로 과도하게 늘어나지 않음 |
| 폭 320 CSS px | 가로 스크롤 없이 한 열로 재배치 |
| 브라우저 200% 확대 | 버튼·문구가 잘리지 않고 세로 스크롤로 접근 가능 |

## 6. 자동 검사

```powershell
npm run check
```

합격 출력:

- 핵심 파일·화면·저장·녹음·채점 상태 통과
- 앱 버전 단일 기준 통과
- 피드백 반영 범위 통과
- 제시 사양·자극 노출·음성 선택 통과
- 채점/선별/ASR/선택형 계산 통과
- 문항 규칙 통과
